Лабы 0–5, существующие корневые файлы, Git-настройки, ветки и индекс скрипт не меняет. Новые материалы добавлены только в перечисленные папки и labs-6-16/.

| Работа | Папка | Запуск |
|---|---|---|

Команды npm выполняются в указанной папке; Node.js 24 LTS рекомендуется. Скрипт не устанавливает зависимости и не запускает Git-команды. В Windows используйте npm.cmd вместо npm, если PowerShell блокирует npm.ps1.

## Статический сервер
Из корня репозитория: node labs-6-16/serve.cjs. Навигатор: http://localhost:8080/labs-6-16/. Существующие package.json и index.html не перезаписываются. Остановить сервер — Ctrl+C.

Для Windows в этой папке есть START-STATIC.bat, START-ZEN-MONEY.bat, START-REACT.bat, START-NEXT.bat и START-ANGULAR.bat. Они устанавливают зависимости в соответствующем проекте при первом запуске. Их выполнение проверяйте на своём компьютере: создание .bat не является проверкой на Windows.

## Структура и сдача
Объединённые проекты 8–9, 10–11, 12–13, 15–16 сохранены как в задании; одиночные папки соответствующих номеров содержат ссылки на общую работу. MVC описан в MVC.md. Тесты №14 не зависят от №0–5. GitHub/Vercel-публикация и устная защита скриптом не выполняются. Все изменения не закоммичены; просмотрите git diff и git status перед собственным коммитом.
