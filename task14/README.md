# Тесты дополнения 6–16
Установите зависимости: `npm install` в ../task10-11 и в этой папке. Затем `npm test` здесь.
10 тестов модели React, 7 тестов React-компонентов, 4 теста моделей Snake/Posts в Node без DOM. Используются реальные исходники №6, №7 и №10–11; №0–5 для этих тестов не нужны.
Проверяются фильтры, сортировка без мутации, создание/удаление/выполнение, хранение, некорректный ввод, форма, сквозной React-сценарий, столкновения и загрузка/повтор после сетевой ошибки.
Для основных сценариев React проверяется примерно 12/14 выбранных случаев (86%): не автоматизированы исчерпание квоты localStorage и браузерные визуальные состояния. Это оценка сценариев, а не строк кода.
RESULTS.txt и tests-result.png — фактический результат проверки этого комплекта. При переносе с переименованием папок тесты запускаются заново командой npm test.
