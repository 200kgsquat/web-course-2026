Проекты

Bag Counter

Computer Vision сервис для детекции, трекинга и подсчёта мешков на конвейерной ленте.

Система обрабатывает видео на GPU, детектирует объекты с помощью RTMDet, отслеживает их через ByteTrack и считает каждый физический объект один раз при пересечении заданной линии.

Обработка выполняется асинхронно: FastAPI принимает запросы, Celery запускает GPU-задачи, Redis используется как брокер и хранилище состояния задач.
